1. About Joinly

Last Updated: August 1, 2026

Joinly is a Discord bot designed to help server owners and administrators manage their communities through customizable welcome, goodbye, and server management features.

Joinly provides tools including:

  • Custom welcome messages
  • Custom goodbye messages
  • Embed customization
  • Placeholder variables
  • Configuration backups
  • Additional server management features

2. Features

Joinly provides features designed to improve Discord server management and customization.

Welcome & Goodbye Messages

  • Customizable embeds
  • Custom titles and descriptions
  • Custom embed colours
  • Images, thumbnails, and footers
  • Placeholder variables
  • Separate welcome and goodbye configurations

Premium Features

  • Additional configuration options
  • Premium-only placeholders
  • Join Analytics
  • Additional server tools
